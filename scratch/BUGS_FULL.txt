Notes Section – Date and Time-Based Segregation
Current Behavior:
Notes entered in the Notes section are getting saved successfully. However, multiple notes are not clearly segregated or organized based on when they were added.
Expected Behavior:
Each saved note should be displayed separately below the Writing Notes section.
Notes should be automatically organized based on their date and time of creation/update, with the latest note displayed first.

Message Notifications and Unread Message Count
Current Behavior:
When a new message is received from a client, no notification/pop-up is displayed to alert the user.
The Messages section does not show the number of unread messages.

Expected Behavior:
A notification/pop-up should appear when a new message is received from a client.
The Messages section should display an unread message count/badge indicating the number of unread messages.
The unread count should update automatically whenever a new message is received and should decrease once the messages are read.

Notification Bar – Dismiss All and Individual Notification Removal
Current Behavior:
The “Dismiss All” option in the notification bar is not working, and notifications remain visible after selecting it.
The cross (×) icon on individual notifications is also not working, so the selected notification remains visible.
Expected Behavior:
Clicking “Dismiss All” should immediately remove all notifications from the notification bar.
Clicking the cross (×) on an individual notification should remove only that particular notification.
The notification count should also update accordingly after notifications are dismissed.
